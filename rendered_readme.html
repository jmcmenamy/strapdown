Strapdown.js

Intro

See here for a more thorough description, all credit goes to the original authors. I made very minor and messy edits.

Note

The headings in this page are just used to show the toc generation.

Changes to original

I forked this to be able to only do toc generation on existing html, no markdown parsing. Instead, I use the Github API to convert markdown to html, and I use this for styling the html.

Motivation

Existing toc generators didn't look as nice as the toc generated by this strapdown. I liked the look of the toc generation in the original, and found it easier to do this than replicate it myself. I stopped converting markdown to html in the javascript, and changed the styling to look more like how Github renders markdown, with light/dark mode support and syntax highlighting.

Methods

I use a workflow to automatically call the Github API and convert the README in this repo to html and commit it, so the github pages site can display it.

Putting it together

Using the workflow, the bundled strapdown.js, and the script in index.html allows for auto publishing a gh pages site that shows the README in the repository similarly to how Github renders READMEs, with light/dark mode support, syntax highlighting, and $\LaTeX
$ support.
